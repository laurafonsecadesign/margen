3. DECISIONES DEL CÓDIGO

He utilizado HTML para organizar cada página y CSS para el diseño.
No hay JavaScript ni frameworks. Los archivos HTML son independientes y
comparten una única hoja de estilos para que los cambios sean consistentes.

En el HTML aparecen etiquetas semánticas (header, nav, main, section,
article y footer) y nombres de clases descriptivos como "cabecera",
"tarjeta", "destacado" o "lectura".

En CSS utilizo Grid para las tarjetas y las estructuras de columnas, y
Flexbox para la navegación y algunos bloques. Las media queries adaptan
la revista a tablet y móvil. El menú móvil usa un checkbox de HTML y
transiciones CSS, así que no necesita JavaScript para abrirse o cerrarse.

4. CÓMO HACER CAMBIOS

- Textos: busca la frase en el archivo HTML correspondiente.
- Colores: cambia las variables que están al principio de css/style.css.
  El rojo actual es #FF5A5B y el granate es #570000.
- Espaciados: ajusta la variable --margen o las reglas de cada sección.
- Tipografías: están definidas en los bloques @font-face y en el body.
- Móvil: busca las reglas @media (max-width: 700px).
- Fotografías o gráficos: reemplaza el archivo de assets/images/ y revisa
  su descripción alternativa (alt).

5. TIPOGRAFÍA Y RECURSOS

Los títulos usan Switzer Regular, en mayúsculas y con letras juntas.
Los párrafos y textos secundarios usan Switzer Light.
El texto "Fuera" del manifiesto de la home tiene una excepción tipográfica:
la opción preferida es ITC Legacy Sans Std Medium Italic. Como esa fuente
comercial no se distribuye en el ZIP, se muestra una cursiva local de
Switzer cuando no está instalada. Consulta creditos.html.

Las fotografías están acreditadas en la página Créditos. También se
incluyen los SVG originales que se utilizan en la revista.

6. COMPROBACIONES DE ENTREGA

- 13 páginas HTML con un H1 y un elemento main en cada una.
- Enlaces entre las páginas, anclas y recursos locales comprobados.
- Imágenes HTML con descripciones alt y rutas relativas.
- Los iconos de navegación se dibujan en SVG, no como emojis.
- CSS organizado por secciones: base, navegación, home, artículos,
  tablet/móvil y animaciones.

Antes de entregar, recomiendo abrir index.html y comprobar la home,
las categorías y algún artículo en escritorio y móvil. También conviene
probar el menú móvil y revisar que las fuentes carguen correctamente.

Este ZIP incluye el código fuente y los recursos necesarios para
revisar cómo está construida MARGEN.
